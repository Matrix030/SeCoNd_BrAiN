# Types of System Calls

1) [[system call|System calls]] can be grouped roughly into six major categories: 
	- **[[Process Control|process control]]**, 
	- **[[File Management|file manipulation]]**, 
	- **[[Device Management|device manipulation]]**, 
	- **[[Information Maintenance|information maintenance]]**, 
	- **[[Communication|communications]]**, and 
	- **[[Protection|protection]]**. 
2) Most of these system calls support, or are supported by, concepts and functions that are discussed in later chapters.
