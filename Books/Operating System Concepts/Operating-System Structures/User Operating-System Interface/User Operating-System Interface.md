# User Operating-System Interface

Here, we discuss two fundamental approaches.  
1) One provides a command-line interface, or **[[Command Interpreter|command interpreter]]**, that allows users to directly enter commands to be performed by the operating system. 
2) The other allows users to interface with the operating system via a [[Graphical User Interfaces|graphical user interface]], or GUI.
