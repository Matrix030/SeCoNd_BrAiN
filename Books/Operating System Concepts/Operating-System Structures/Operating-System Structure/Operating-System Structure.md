# Operating-System Structure

1) A system as large and complex as a modern operating system must be engineered carefully if it is to function properly and be modified easily. 
2) A common approach is to partition the task into small components rather than have one monolithic system.
3) Each of these modules should be a well-defined portion of the system, with carefully defined inputs, outputs, and functions.
