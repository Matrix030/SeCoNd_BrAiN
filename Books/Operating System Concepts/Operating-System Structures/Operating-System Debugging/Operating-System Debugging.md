# Operating-System Debugging

1) Broadly, **debugging** is the activity of finding and fixing errors, or **bugs**, in a system. Debugging seeks to find and fix errors in both hardware and software. Performance problems are considered bugs, so debugging can also include **performance tuning**, which seeks to improve performance by removing **bottlenecks** in the processing taking place within a system.
2) In this section, we explore debugging kernel and process errors and performance problems.
