# Design Goals

1) The first problem in designing a system is to **define goals and specifications**. At the highest level, the design of the system will be affected by the choice of hardware and the type of system: batch, time shared, single user, multiuser, distributed, real time, or general purpose.
2) The requirements can be divided into two basic groups: 
	- _user_ goals and 
	- _system_ goals.

3) Users desire certain obvious properties in a system. The system should be:
	- convenient
	- easy to learn
	- reliable
	- safe
	- fast
4) A similar set of requirements can be defined by those people who must design, create, maintain, and operate the system. The system should be: 
	- easy to design
	- implement
	- maintain; and it should be flexible 
	- reliable 
	- error free
	- efficient.
