# Computer System Components

A computer system can be divided roughly into four components: the _hardware,_ the _operating system,_ the _application programs,_ and the _users_
![[Pasted image 20260525153734.png]]

1) The **hardware**—the central processing unit (CPU), the memory, and the input/output **(I/O) devices**—provides the basic computing resources for the system.
2) The application **programs**—such as word processors, spreadsheets, compilers, and Web browsers—define the ways in which these resources are used to solve users’ computing problems.
3) The operating system controls the hardware and coordinates its use among the various application programs for the various users.
4) We can also view a computer system as consisting of hardware, software, and data.
5) The operating system provides the means for proper use of these resources in the operation of the computer system.
6) An operating system is similar to a _government_.
7) Like a government, it performs no useful function by itself.
8) It simply provides an _environment_ within which other programs can do useful work.

To understand more fully the operating system’s role, we next explore operating systems from two viewpoints: that of the [[User View|user]] and that of the [[System View|system]].
