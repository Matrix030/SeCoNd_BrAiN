# Introduction

1) An **operating system** is a program that manages the computer hardware. 
2) It also provides a basis for application programs and acts as an intermediary between the computer user and the computer hardware. 
3) Mainframe operating systems are designed primarily to optimize utilization of hardware. Personal computer (PC) operating systems support complex games, business applications, and everything in between. 
4) Operating systems for handheld computers are designed to provide an environment in which a user can easily interface with the computer to execute programs. 
5) Thus, some operating systems are designed to be _convenient,_ others to be _efficient,_ and others some combination of the two.
6) We begin by discussing the basic functions of system startup, I/O, and storage. 
7) We also describe the basic computer architecture that makes it possible to write a functional operating system.

Because an operating system is large and complex, it must be created piece by piece. Each of these pieces should be a well-delineated portion of the system, with carefully defined inputs, outputs, and functions. In this chapter, we provide a general overview of the major components of an operating system.

**CHAPTER OBJECTIVES**
• To provide a grand tour of the major components of operating systems.
• To describe the basic organization of computer systems.
