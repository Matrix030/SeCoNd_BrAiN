# Web-Based Computing

1) Web computing has increased the emphasis on networking. Devices that were not previously networked now include wired or wireless access. Devices that were networked now have faster network connectivity, provided by either improved networking technology, optimized network implementation code, or both.
2) The implementation of Web-based computing has given rise to new categories of devices, such as **load balancers**, which distribute network connections among a pool of similar servers.
