# Communication in Client-Server Systems

1) In Section 3.4, we described how processes can communicate using shared memory and message passing. These techniques can be used for communication in client-server systems (Section 1.12.2) as well. In this section, we explore three other strategies for communication in client-server systems: **sockets**, **remote procedure calls (RPCs)**, and **pipes**.
